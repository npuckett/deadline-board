# Changelog

## 0.1.0 — 2026-08-25

First release.

- Desktop widget (medium and large) listing deadlines soonest first with days/hours countdowns and urgency colors.
- Deadlines disappear from the widget automatically once they pass; the editor keeps them under a Past filter.
- Clicking a widget row opens the deadline's link in the default browser, or the editor when it has no link.
- Menu bar app with the next three deadlines, editor window, and settings — no dock icon.
- Editor with Upcoming/Past/All filters; clicking a deadline opens the combined edit/delete form.
- Local notifications at configurable offsets (14d to 1h) with an Open Link action.
- "Add Deadline" from Spotlight and Shortcuts.
- Local only: JSON in an App Group container, no network, no accounts, no third-party code.
